File format

A CSV with a header row, or a JSON list of objects with the same keys. Columns:

  • name (required): goals are matched by name, ignoring case, within the same scope.
  • target_amount (required): decimal dollars such as 1250.00.
  • priority (required): a whole number, 1 is funded first.
  • depends_on: the name of another row in the file with the same scope. Funded only after that goal.
  • time_sensitive: true or false.
  • target_date: YYYY-MM-DD, or blank for no date.
  • scope: private (default) or household.

Importing the same file again changes nothing. A column you leave out keeps each saved goal as it is, and a blank cell in a column you include clears that value (in JSON, a key missing from one object counts as blank). A name that matches an archived goal updates it and leaves it archived. Goals missing from the file are listed, never deleted.
